# EVE-DETR

## Description
This is the repo for the code of "EAE-DETR: A Lightweight Model for Real-Time Traffic Sign Detection in Complex Weather Conditions"
## Model
EAE-DETR: A Lightweight Model for Real-Time Traffic Sign Detection in Complex Weather Conditions model configuration file is rtdetr-Efficientvim-ASF-EDFFN.yaml in the directory [./ultralytics/cfg/models/mine/](https://github.com/conng123/Improved-RTDETR/blob/main/ultralytics/cfg/models/mine/rtdetr-Efficientvim-ASF-EDFFN.yaml).

#### Installation
```
pip install -r requirements.txt
```

#### Training

###### Single GPU training
```
python train.py 
```


#### Testing

```
python val.py 
```
